# Backend

This directory will contain deployment configuration for the Armiarma network crawler.

The crawler source code is currently located in `data/tools/armiarma/` as a git submodule. Deployment to a Hetzner VPS server is in progress to enable continuous network data collection.

## Current Status

- Crawler: Forked Armiarma (supports Ethereum, Polygon, Filecoin, Celo)
- Location: `data/tools/armiarma/` (git submodule)
- Deployment: Planned for Hetzner VPS
- Purpose: Collect node IP addresses for GDI calculations

## Future Work

Deployment configuration and infrastructure-as-code will be added here once the server provisioning is complete.
